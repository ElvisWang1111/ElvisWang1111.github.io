# Blog 写作说明

这个目录用于管理个人博客文章。

## 推荐流程

1. 复制 `posts/post-template.md` 并重命名，例如：`posts/2026-05-20-my-topic.md`。
2. 按模板填写 `title`、`date`、`summary`、`tags` 和正文。
3. 打开 `blog/index.html`，在文章列表中新增一条卡片链接。
4. 在主页 `index.html` 的 Blog 区域可保持不变，统一引导到 `./blog/`。

## 命名建议

- 文件名：`YYYY-MM-DD-slug.md`
- 例子：`2026-05-20-agent-workflow.md`

## 模板位置

- 主模板：`posts/post-template.md`
- 示例文章：`posts/2026-05-14-hello.md`
